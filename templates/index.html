About this Project
Research Paper
AI Driven Early Detection of Economic Slowdown in India Using Multi Sector High Frequency Indicators

Presented at NCMPCS-2026, Department of CSE, FOET, Dr. Shakuntala Misra National Rehabilitation University, Lucknow.
ML Model
Ensemble of Random Forest + Gradient Boosting trained on 32 quarterly observations (2018–2025).
5-fold CV accuracy: 78.6%  |  LOO accuracy: 68.8%
Data Sources
MOSPI (GDP, CPI, IIP, Agri GVA) · RBI (Credit, Repo Rate, Forex) · CMIE CPHS (Unemployment) · S&P Global (PMI) · Ministry of Commerce (Exports)
Tech Stack
Python · Flask · scikit-learn · pandas · Chart.js · Vercel · GitHub Open Datasets (live CPI/GDP)
